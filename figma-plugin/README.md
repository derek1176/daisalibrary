# 다이사(da24) 디자인시스템 검증기 (Figma Linter Plugin)

> **버전**: v1.0.0  
> **지원 대상**: 다이사(da24) B2C 고객향 & B2B 파트너향 피그마 디자인 파일

---

## 🚀 1. 피그마에 플러그인 10초 만에 등록하는 방법

Figma 데스크톱 앱에서 바로 로컬 플러그인으로 등록하여 사용할 수 있습니다:

1. **Figma 데스크톱 앱**을 실행합니다.
2. 상단 좌측 메뉴(피그마 아이콘) 클릭 ➔ **Plugins** ➔ **Development** ➔ **Import plugin from manifest...** 선택
3. 파일 탐색기에서 다음 경로의 `manifest.json` 파일을 선택합니다:
   ```
   [daisalibrary 저장소 폴더]/figma-plugin/manifest.json
   ```
4. 완료! 이제 피그마에서 우클릭 ➔ **Plugins** ➔ **Development** ➔ **다이사(da24) 디자인시스템 검증기**를 실행할 수 있습니다.

---

## ✨ 2. 핵심 기능

### 1) 고객향(B2C) vs 파트너향(Partner) 독립 검증 모드
- **상단 토글 스위치**로 모드를 자유롭게 전환할 수 있습니다.
- 🚨 **독립 원칙 준수**: 고객향 규칙과 파트너향 규칙은 절대 섞이지 않으며, 각각의 공식 MD 명세서 기준을 엄격하게 적용합니다.

### 2) 세부 검증 항목
| 카테고리 | 고객향 (Customer) 기준 | 파트너향 (Partner) 기준 |
| :--- | :--- | :--- |
| **🎨 컬러 토큰** | 공식 13대 Hex 토큰 외 임의 색상 100% 검출 | 파트너 16대 Hex 허용 (레거시 `#999999`, `#BCC0C6` 차단) |
| **🔤 서체** | **`Pretendard` 단일 서체** 필수 | Pretendard 또는 Noto Sans KR |
| **🔤 폰트 크기** | **짝수 6종 (`12, 14, 16, 18, 20, 24px`)**<br>(홀수/소수점 금지, 마이크로 배지 10/11px 예외) | **7단계 스케일 (`14, 16, 18, 20, 24, 28, 32px`)**<br>(기본 본문 18px, **14px 미만/12px 절대 금지**) |
| **🔤 자간** | `letter-spacing: -1%` (`-0.01em`) 고정 권장 | `letter-spacing: -1%` 고정 권장 |
| **📐 모서리 곡률** | **높이별 3단계 자동 판별**<br>- 높이 < 80px: `8px`<br>- 높이 80~240px: `10px`<br>- 높이 ≥ 241px: `12px`<br>(모달/시트 상단 16px 허용) | **전사 통일 `6px` 고정**<br>(소형 태그/칩 4px 허용, 고객향 10px/16px 엄격 차단) |
| **📏 보더 두께** | **`1px solid`** 원칙 (두꺼운 2px 금지) | 1px solid (포커스 2px 외 1px 원칙) |
| **📱 레이아웃** | 모바일 프레임 `360px`, 본문 컨테이너 `312px` | 모바일 `360px (본문 312px)`, PC 주문카드 `627px` |
| **😀 이모지** | 네이티브 이모지(`📦, 🔥 등`) 검출 차단 | 네이티브 이모지 검출 차단 (SVG/아이콘 대체) |

### 3) 캔버스 레이어 인터랙션
- **🔍 위치 이동 (Focus)**: 리포트 내 이슈를 클릭하면 피그마 캔버스에서 해당 레이어를 즉시 선택하고 뷰포트 정중앙으로 확대 이동합니다.
- **⚡ 빠른 수정 (Auto-Fix)**:
  - 비표준 폰트 크기 ➔ 가장 가까운 표준 규격 크기로 즉시 변경
  - 잘못된 모서리 곡률 ➔ 높이 기준 표준 규격(고객 8/10/12px, 파트너 6px)으로 즉시 적용
  - 두꺼운 보더 ➔ 1px로 보정
  - 자간 ➔ -1%로 자동 보정
- **⚡ 일괄 자동 수정 (Fix All)**: 자동 보정 가능한 모든 이슈를 한 번의 클릭으로 일괄 적용
- **📋 마크다운 결과 복사**: 검증 리포트를 기획자/개발자 공유용 Markdown 표 형태로 클립보드에 복사

## 🛠️ 3. 소스코드 빌드 및 개발

플러그인 코드를 직접 수정하는 경우 다음 명령어로 빌드합니다:

```bash
cd figma-plugin
npm run build
```

코드를 실시간 감시하며 작업하려면:
```bash
npm run watch
```
